# Dataset Information

## Dataset Name
Hotel Booking Demand

## Dataset Source
[Kaggle – Hotel Booking Demand](https://www.kaggle.com/code/mohammadsabeti/hotel-booking-dataset-analysis)

## Dataset Description

The dataset contains 119,390 hotel booking records for City Hotels and Resort Hotels between July 2015 and August 2017.

## Download Instructions

1. Visit the Kaggle dataset link.
2. Download the dataset.
3. Extract the downloaded files.
4. Place the required CSV file in this folder.
5. Run the Jupyter Notebook.

**Note:** The original dataset is not included in this repository. Please download it from the original source and follow its licensing and usage conditions.
